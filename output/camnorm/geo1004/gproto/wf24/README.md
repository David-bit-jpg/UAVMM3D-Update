## 1. 中间域贴图会不会泄露真实目标位置（审稿人可能问）
做法：把仿真机身贴到**真实训练集单帧**背景上。背景窗要避开这张真实图里本来就有的那架无人机——
**避开用的是我们自己检测器在这张无标签图上的单帧检测**（测距库：最终检测器 3 集成 + 翻转，置信 ≥0.5，窗口平移 1.8 倍框宽；朝向库：单帧检测器置信 ≥0.6，避开外扩 20% 的框）。
代码核对：`geo1004/xpaste_bank_sf2.py`、`gproto/wf20/review/bank_kz_sf_v3.py`——选窗只读检测记录 `pred/conf`，真值只在最后单独一段统计"窗里有没有真机"。
- 只用训练集图像（验证 / 测试图像从不进背景库）；检测器本身也只用无标签训练图 + 仿真训练。
- 这和自训练用的伪标签是同一种信息（模型自己的预测），部署时同样可得，不是真值。
- 为什么必须避开（`diag_randwin.py`，真值只诊断）：同一帧里随机取窗、不避开时，含 ≥10% 真机的窗 测距库 **20.6%**、朝向库 **71.9%**（朝向窗大，近处机身时窗口接近整幅图）；用自己检测避开后 **0.10%** / 0.7–1.8%。不避开就等于给一张"只有贴上去那一架"的标签配了一张有两架飞机的图。
