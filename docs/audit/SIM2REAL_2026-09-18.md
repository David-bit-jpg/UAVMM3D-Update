# 纯仿真 → MAV6D 零样本：2026-09-18 的定位、改动与结果

一句话：零样本位置中位从 **4.591 m 降到 0.522 m**（折算角度同时从 39.4° 做到 41.8°，2D 中心 9 px），
全部改动都在模型/训练侧，没有改采集、没有针对 MAV6D 调任何东西。剩下的瓶颈是一个 ~20% 的尺度偏差，
它在所有模型侧手段下都没被消掉；用 17 帧真实标注标定一个标量可以把位置做到 0.303 m。

## 1. 问题定位（每条都有测量）

深度失败的形态：**响应正确、零点偏移**。
- 帧内围绕目标放大 1.0~1.8 倍，真实图上预测的机身倍数斜率 **0.98**（仿真 1.02），但整体偏 **1.27 倍**。
- 等价说法：模型把真实目标的表观大小系统性读小约 21%。

逐条排除（都在真实域或两域对照上测过）：

| 假设 | 测量 | 结论 |
|---|---|---|
| 标注框/投影几何不同 | 形状因子 仿真 1.36 / MAV6D 1.38 | 排除 |
| MAV6D 固定 0.34 m 框的误差 | phantom4 1.25、mavic2 1.30 | 排除 |
| 细节量/清晰度 | 真实图降采样 1.5~3x → 1.20~1.25 | 排除 |
| 亮度/对比度/gamma/锐化 | 六种变换全在 1.25~1.30 | 排除 |
| 读「整幅画面放大了多少」的捷径 | 域内固定裁窗，斜率 0.96~0.99、同机型内 0.86~1.07 | 排除 |
| 深度读在偏了一格的位置 | 改在真值中心格读 → 1.38，更差 | 排除 |
| BN 统计量漂移 | 无标签真实图重算 BN → 1.40，更差 | 排除 |
| 目标外圈结构（桨叶等） | 仿真抹掉框内 0.64~1.0 环带 → 1.24（抹背景无影响） | 部分相关，但训练侧随机化后只从 1.28 走到 1.22 |

**根因落点**：`size2d` 头（显式监督的 2D 跨度）域内 0.99/0.99、相关性 0.94，**真实域宽 0.82~0.85、高 0.46~0.53**，
而深度偏移 1.22 ≈ 1/0.82。即「模型觉得目标在图上多大」这一个 2D 量不迁移，其余环节（检出 85%、2D 中心 9 px、
用真值深度时位置 0.05 m）都是好的。

## 2. 三项改动（代码开关，缺省关，行为不变）

1. **`POST_PROCESSING.SIZE2D_MODE: width`** —— 几何解深度只用水平跨度。
   理由：多旋翼竖直方向薄，竖直跨度小且随姿态剧烈变化；水平跨度对应旋翼展，是最稳的维度。
   实测同一份权重切换：位置中位 **1.240 → 0.464 m（6 轮）**、**2.005 → 0.766 m（24 轮）**，两次都约 2.7 倍。
2. **目标级随机化增广** `AUG.target_ring / target_ring_core / target_ring_alpha / target_blur / target_blur_len`
   —— 按 GT 2D 框对目标外圈做随机衰减、对目标区域做随机运动模糊。
   实测把「仿真上对外圈结构的敏感性」从 1.24 压到 1.07。
3. **`VIEW_AUG.t_range / max_upscale`** —— 裁窗按「机身倍数」反算而不是独立随机抽。
   实测 corr(t, log 机型尺寸) −0.79 → −0.55（模拟 −0.50），各机型的 t 分布从完全不重叠变成大量重叠。

其余新增但结论为负的开关：`DEPTH_TARGET: log_ratio`（机身倍数深度）、`MAKE_KP2D` + `POSE_FROM_KP2D`（关键点 + PnP）。

## 3. 结果（MAV6D test 4800 帧，纯仿真零样本）

协议：训练预算**事先固定为 5 轮**（不按真实结果挑轮次）；报「给定机型尺寸」与「不给尺寸」两个口径。

| 臂 | 位置中位（给尺寸） | 不给尺寸 | 深度中位 | <0.2 m | 角度（折算） |
|---|---|---|---|---|---|
| R1 旧基线（回归深度） | 4.591 m | — | 3.334 | 0.5% | 39.4 |
| 最好配方 种子 0 | 0.522 | 0.766 | 0.369 | 22.3% | 62.5 |
| 最好配方 种子 1 | 0.501 | 0.836 | 0.388 | 22.0% | 65.1 |
| 最好配方 种子 2 | 0.402 | 0.546 | 0.381 | 27.9% | 59.9 |
| + MixStyle 种子 0 / 1 / 2 | 0.482 / 0.442 / 0.432 | 0.689 / 0.644 / 0.545 | 0.36~0.43 | 25% | 62.7 |
| **双权重融合**（位置取第 5 轮、朝向取第 24 轮） | **0.522** | 0.774 | — | 22.9% | **41.8** |
| 参考：17 帧标定一个标量后 | **0.303** | — | — | 33.3% | — |
| 参考：MAV6D 上真实训练 | 0.045 | — | — | 99% | — |

**MixStyle 应当进默认配方**：三种子均值 给尺寸 0.475 → 0.452、不给尺寸 0.716 → 0.626，且三个种子在「不给尺寸」这一列
全部变好。机制上一致：MixStyle 堵的就是「靠特征统计量判断」，而不给尺寸时模型必须自己估机型，受这条捷径影响最大。

深度与朝向对训练时长的需求相反：位置第 4~5 轮最好、之后退化（0.50 → 0.79 m）；朝向一路变好（折算 62 → 42）。
冻结骨干只训旋转头无效（15 轮角度不动），说明朝向的提升来自骨干特征本身；因此实用方案是双权重融合（两次前向）。

## 4. 试过并判负的方向（都有数据）

- **关键点 + PnP**（8 角点回归 + solvePnP）：域内一路收敛（角点误差 20 → 6.7 px、隐含尺度 0.55 → 0.94），
  **真实域纹丝不动（30 px、尺度 0.45）**。原因：3D 框角点大多悬在空中，不对应可辨识的图像特征，
  预测它们等价于预测尺寸。往返自检精确（1e-7 m），PnP 敏感度：角点 1/2/4 px → 位置 0.067/0.129/0.206 m。
- **锚点蒸馏**（把 size2d/dim 钉在早期教师上，骨干自由）：位置仍退（0.63 → 0.82 m），角度只到 54°。
  约束只加在仿真数据上，而退化的本质是「仿真更好、真实更差」，所以钉不住真实行为。
- **推理期多尺度平均**：0.415 → 0.420（不同裁窗下的误差是相关的）。
- **只用仿真的稳健性选轮**（目标被扰动后还准不准）：选出第 21/23 轮，与域内选轮几乎无差别（0.762 vs 0.782）。
- **加强目标级随机化**：0.854，比原版更差。**冻结骨干 BN**：无明显作用。**AdaBN**：1.26 → 1.40，更差。

## 5. 仍然开着的问题

1. 那 ~20% 的尺度偏差没有被任何模型侧手段消掉。已知能消掉它的只有：给定物体尺寸 + 一次标量标定（10~20 帧）。
2. 角度折算 41.8°、未折算 102°，说明 180° 机头歧义仍然严重（仿真缺红色前臂灯这类机头线索，四旋翼前后近似对称）。
   建议把朝向拆成「模 180° 的朝向」与「机头朝哪边」两件事分别报。
3. 训练越久跨域深度越差，而且没有可靠的、只用仿真的选轮判据。现在靠固定训练预算规避，不是根本解法。
