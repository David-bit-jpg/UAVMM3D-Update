# 无人机单目 3D 检测：仿真 → 真实，完全单帧最终版（11-09）

**做什么**：只输入**一张**彩色图，输出无人机的 3D 位置、尺寸和朝向；部署时不看任何其他帧。
**数据**：标签只来自仿真；真实数据（MAV6D）只用训练集的**无标签**图片；真实标签**只在最后打分**时使用。红外和 LiDAR 只在仿真里当"老师"，部署只用彩色图。

> 与本分支 `release/README.md`（11-06 版）的区别：那一版推理和伪标签修正用到了多帧（时间中位背景、等后 5 帧）；这一版每一步只用本帧图像 + 在无标签真实训练集上求一次的全局常数。

---

## 1. 方法结构

**两个特点不同的老师（仿真里）**
- 红外老师：红外图里机身轮廓清楚 → 教网络"轮廓有多宽 → 多远"（测距网络的剪影辅助监督）。
- LiDAR 老师：懂机身三维形状 → 教网络"8 个角点 → PnP 求距离与朝向"（关键点网络的 LiDAR 深度剪影辅助监督）。
- 两者看的物理量不同，真实帧上的误差几乎不相关（相关 −0.1~0.3）。

**中间域**：用红外剪影把仿真机身抠出来，贴到真实**单帧**背景上（标签精确）。

**两个彩色学生，各三段**

| 段 | 测距学生（depth refiner） | 朝向学生（keypoint student） |
|---|---|---|
| ① 仿真打底 | 仿真 + 中间域，精确距离；红外剪影辅助 | 仿真 + 中间域，精确朝向；LiDAR / 红外剪影辅助 |
| ② 适应真实 | 真实图与慢更新自身一致 + 特征对抗 | 真实图重估 BN 统计 |
| ③ 伪标签精修（仿真有标签 + 真实无标签混合） | **两教师合并伪目标**：log z = 0.85·log z_红外 + 0.15·(log z_LiDAR − b_k) | 教师组伪朝向（红外组与 LiDAR 组读数差 ≤10° 才用）+ 四旋翼对称关键点损失 + **镜像一致损失** |

- z_红外 = 红外教出的测距网络修正后的伪距离（全严格单帧伪标签）；z_LiDAR = LiDAR 教出的朝向关键点网络（11-08 最终版 5 个 + 镜像读数）8 角点 SA-TM 融合 + PnP 的深度；b_k = 两路刻度差，按机身颜色原型（暗/亮）在无标签训练帧上取中位。
- 镜像一致损失：同一真实帧与其左右镜像各前向一次，镜像角点图精确换算回原图（格子列 c→63−c、角点水平偏移取反、角点按机身 y 轴镜像换号）后，与原图输出在伪标签中心格上 L1 一致；权重 12（= 关键点损失权重，不调）。

**部署（单帧）**：检测器（3 集成 + 翻转，不开时序背景）→ 测距学生 5 个修正距离 → 朝向学生 5 个读原图 + 镜像（10 成员 SA-TM + PnP）→ 角点 PnP 深度与测距学生距离在对数上按 0.85 / 0.15 合并（0.15 在有标签验证集上选，0.15–0.25 都接近）→ 高度 = 颜色原型高度比 × 长宽均值。

## 2. 结果（真实 MAV6D；区间 = 按视频段整簇 bootstrap 300 次）

| 配置 | 验证 UDS | 测试 UDS | 测试 AP | 测试位置误差 m（中位） | 测试朝向误差° / 航向中位° | 验证朝向误差° / 航向中位° |
|---|---|---|---|---|---|---|
| 11-08 最终合规版 | 62.76 | 68.38 | 53.21 | 0.235（0.176） | 13.67 / 5.96 | 21.11 / 13.36 |
| + 部署镜像读数 + 部署两种测距合并 | 64.87 | 71.59 | 58.89 | 0.215（0.147） | 13.08 / 5.51 | 20.47 / 12.35 |
| **最终（+ 两教师合并伪目标 + 镜像一致损失）** | **65.70** | **72.31** | **60.15** | **0.212（0.140）** | **12.86 / 5.37** | **19.69 / 11.58** |

- 最终 vs 11-08：验证 +2.95 [+0.75, +5.44]，测试 +3.93 [+2.05, +5.53]；测试 AP +6.94 [+3.71, +9.68]；测试位置误差 −0.02 m [−0.04, −0.00]；朝向误差 验证 −1.41° [−2.02, −0.56]、测试 −0.80° [−1.61, −0.16]。
- 两教师合并伪目标（3 种子 vs 同时重训对照，测距学生单独）：验证 +0.74 [+0.05, +1.24]，测试 +1.40 [+0.57, +2.02]。
- 镜像一致损失（单网，3 种子，验证与测试 3/3 全好）：航向均值 16.68→15.56° / 10.51→9.37°。
- 常数改用无标签验证集图像统计时测试 UDS 73.46（参照；主数字用训练集常数）。
- 判负（未进最终）：第三种测距（LiDAR 结构点 PnP）、按原型统计教师分歧重分配权重、逐帧一致度加权。
- 指标定义同 `release/README.md` §2（UDS 为自定义 NDS 式综合分）。原始记录在 `results/`，实验笔记（含原理与全部臂）在 `results/EXPERIMENT_NOTES.md`。
