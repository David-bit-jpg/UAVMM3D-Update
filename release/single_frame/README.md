# 无人机单目 3D 检测：仿真 → 真实，完全单帧最终版（11-09 精简版）

**做什么**：只输入**一张**彩色图，输出无人机的 3D 位置、尺寸和朝向；部署时不看任何其他帧。
**数据**：标签只来自仿真；真实数据（MAV6D）只用训练集的**无标签**图片；真实标签**只在最后打分**时使用。红外和 LiDAR 只在仿真里当"老师"，部署只用彩色图。

> 与本分支 `release/README.md`（11-06 版）的区别：那一版推理和伪标签修正用到了多帧；这一版每一步只用本帧图像 + 在无标签真实图像上求一次的全局常数。
> 唯一的间接例外：位置伪框和朝向裁窗所用的早期网络，训练时接触过跨帧伪标签（见 `release/README.md`）。

---

## 1. 方法结构（15 个网络）

| 网络 | 个数 | 作用 |
|---|---|---|
| 红外关键点老师 | 1 | 只看仿真红外图；给"红外蒸馏"朝向网络当模仿对象 |
| 被老师塑形的朝向网络 | 6 | 红外蒸馏 ×2、LiDAR ×2、红外+LiDAR ×2；只用来给真实帧出伪朝向（红外+LiDAR 两个同时是学生的初始化） |
| 高度网络 | 1 | 学 LiDAR 结构点；给按颜色类的机身高宽比常数 |
| 检测器 | 3 | 整图找无人机（部署：3 个平均 + 翻转） |
| 测距网络 | 2 | 修正距离；仿真里学红外剪影，真实域用两教师合并伪距离精修 |
| 朝向学生 | 2 | 读 8 个角点 → PnP 得朝向和第二个距离；真实域自训练 + 镜像一致损失 |

**训练顺序（一条直线）**
1. 仿真：老师答案（红外剪影、LiDAR 机身图、结构点、抠图）→ 红外关键点老师、6 个塑形网络、高度网络、检测器、测距网络第一段。中间域：仿真机身贴到真实**单帧训练集**背景上（标签精确）。
2. 位置：测距网络第二段（适应真实）→ 位置伪框 → 检测器自训练。
3. 朝向：6 个塑形网络对称集成出伪朝向，**红外蒸馏组与 LiDAR 组相差 ≤10° 才用**（4,289 帧里 1,525 帧）→ 朝向学生 ×2（仿真精确标签 + 四旋翼对称角点损失 + 镜像一致损失）。
4. BN 统计重估：学生和高度网络在全部合格真实训练裁窗上重估，随后求高宽比常数。
5. 位置自训练：最终朝向学生在全部真实训练帧上读角点 → PnP 深度 z_L；与红外教的距离 z_IR 合并成伪距离 `log z = 0.85·log z_IR + 0.15·(log z_L − b_k)` → 测距网络第三段。
6. 部署：检测器 → 测距网络 ×2 → 朝向学生 ×2（原图 + 镜像 = 4 个读数）→ 两种距离按同一公式合并（部署 b_k 取无标签验证集图像）。

**中间域会不会泄露真实目标位置**：背景窗只取训练集图像，用**模型自己在这张无标签图上的单帧检测**避开原有无人机，不读真值（`xpaste_bank_sf2.py`、`wf20/review/bank_kz_sf_v3.py`）。必须避开：同一帧里随机取窗时，测距背景窗 20.6%、朝向背景窗 71.9% 含 ≥10% 的真机；避开后 0.10% 和 0.7–1.8%（`wf24/diag_randwin.py`，真值只诊断）。

**精简时去掉的**（证据见 `gproto/wf24/README.md`）：纯彩色对照组（5 个网络）和"老师⇄纯彩色"第二级互验；视角原型损失；老师组和学生从 5 个减到 2 个；高度网络 2→1；第三种距离（结构点 PnP，从未进最终版）；"上一轮学生"。

## 2. 结果（真实 MAV6D；区间 = 按视频段整簇 bootstrap 300 次）

| 配置 | 验证 UDS | 测试 UDS | 测试 AP | 测试位置误差 m（中位） | 测试尺寸误差 cm | 测试朝向误差° / 航向中位° | 验证朝向误差° |
|---|---|---|---|---|---|---|---|
| 11-08 最终合规版 | 62.76 | 68.38 | 53.21 | 0.235（0.176） | 1.83 | 13.67 / 5.96 | 21.11 |
| 精简前（35 个网络） | 65.70 | 72.31 | 60.15 | 0.212（0.140） | 1.83 | 12.86 / 5.37 | 19.70 |
| **最终（精简，15 个网络）** | **66.06** | **72.16** | **60.03** | **0.210（0.138）** | **1.80** | 13.51 / 5.85 | 20.53 |

- 最终 vs 11-08：UDS 验证 +3.30 [+1.14, +5.47]、测试 +3.78 [+2.34, +5.42]；测试 AP +6.81 [+4.25, +9.60]；测试位置误差 −0.02 m [−0.04, −0.01]；朝向误差两集合都跨 0。
- 精简 vs 精简前：综合分持平（验证 +0.36 [−0.41, +0.78]、测试 −0.15 [−0.57, +0.58]）；朝向误差 +0.83° / +0.64°，区间不跨 0（只有 2 个朝向学生；3 个时测试 13.16°）。
- 两教师合并伪距离 vs 只用红外伪距离（测距学生单独，3 种子）：验证 +0.67 [+0.03, +1.27]、测试 +1.47 [+0.58, +2.04]。
- 逐步（测试 UDS）：仅位置分支 67.99 → 加朝向自训练 68.61 → 加合并伪距离 70.09 → 加部署合并 72.16；每一步区间都不跨 0（见 `wf24/README.md` §7）。
- 测试近 / 中 / 远（<3 / 3–4 / ≥4 m）：AP 62.59 / 65.73 / 49.76，UDS 72.71 / 75.79 / 66.62。
- 指标定义同 `release/README.md` §2（UDS 为自定义 NDS 式综合分）。实验笔记在 `results/EXPERIMENT_NOTES.md` 与 `output/camnorm/geo1004/gproto/wf24/README.md`。

## 3. 怎么跑

路径占位符与环境见 `release/README.md` §3.0（`python release/fix_paths.py ...`）。命令按研究时实际用过的顺序整理，**没有从头到尾连续跑过一次**；上游产物按 `release/README.md` 与 11-08 的单帧整链流程生成。脚本：`run_train_final.sh`、`run_deploy_final.sh`。
