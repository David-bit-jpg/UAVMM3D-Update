# wf23/fusetrain：把"两种独立测距合并"搬进训练（11-09）

起点：部署时合并红外教的测距（z_fin）与 LiDAR 教的角点 PnP 测距（z_kp），测试综合分 68.38 → 71.59（wf23/mirror）。
这里做两件事：① 第三种测距 + 无标签三角互估定权重；② 用合并后的距离当真实训练帧上的新伪目标，重训测距学生。
真值只用于打分与诊断。

## 1. 第三种测距（LiDAR 结构关键点 + PnP）—— 判负

- 做法（`kps_depth.py`）：关键点高度比网络（仿真里学 8 个 LiDAR 结构点的 2D 位置 + 归一化 3D 布局，单帧 AdaBN，种子 0/1）在部署同窗上解 PnP，取 log t_z；常数按颜色原型在无标签图像上定。
- 三角互估（`tri_eval.py`）：若三种测距误差互不相关，Var(m_i − m_j) = v_i + v_j，三个方差无标签可解 → 逆方差合并。
- 结果（真值诊断，去偏误差稳健 σ；测试）：
  | 颜色类 | 测距网络 | 角点 PnP | 结构点 PnP | 相关 网络-角点 | 网络-结构点 | 角点-结构点 |
  |---|---|---|---|---|---|---|
  | 深色（≈mavic2） | 8.5% | 19.8% | 38.3% | 0.49 | 0.37 | 0.57 |
  | 亮色（≈phantom4） | 6.0% | 9.6% | 15.8% | 0.02 | −0.00 | 0.49 |
- 结构点测距本身误差大，且与角点测距同出 LiDAR 教的关键点网络，误差相关 0.5 → 三角互估的独立前提不成立，角点方差被估成负数、权重全给角点 → 测试 53.86（不合并 68.51，固定 0.15 为 71.59）。判负。
- 顺带的发现：深色机上测距网络与角点的误差相关 0.49（亮色≈0）—— 合并的增益主要来自亮色机。

## 2. 合并距离当伪目标重训测距学生（进行中）

- 原伪目标：δ_伪 = log(z_伪 / z_P0)，z_伪 = 全严格单帧伪标签（检测 × 红外教的测距修正）。
- 新伪目标：log z_合 = (1−w)·log z_伪 + w·(log z_kp − b_k)，b_k = 颜色原型上 median(log z_kp/z_伪)（无标签训练集）。
- 另一臂："两教师一致度"逐样本权重 a = exp(−r²/2τ²)，r = 两教师（去偏后）之差，τ = 数据自身稳健尺度。
- 训练帧诊断（`build_targets.py`，间隔 3 的帧，只覆盖 1/3 裁窗）：有角点测距的裁窗上伪目标误差 |δ−δ真| 0.0565 → 0.0511（w=0.15，−10%），w=0.30 为 0.0521。
  深色机伪标签误差与角点误差相关 0.39，亮色 −0.01。

## 3. 合并方案（用户 11-09 下午："有用的一起加，loss 放在特别的地方；2、3、4 一起做"）

总原则（来自 wf23 剖析）：整体偏差已修完，剩下的是逐帧误差，主要由前景决定（机型、模糊、对比度）；学生照抄老师的错，
所以只能靠"误差互不相关的测量"来平均。部署时已证明的两次测量（镜像视图、红外⇄LiDAR 两种测距）这里搬进训练。

| 编号 | 模块 | 放在哪 | 用到的 | 相关旧实验 → 为何失败 → 这次怎么避开 |
|---|---|---|---|---|
| 1 | 两教师合并伪目标 | 测距学生的真实帧回归损失 | 无标签真实样本、红外教师（轮廓宽）、LiDAR 教师（角点几何） | 旧：伪标签只来自红外这一路，学生把它的逐帧错学进去 → 现在目标本身先平均掉一部分逐帧错（训练帧诊断 −10%） |
| 2 | 镜像等变一致损失 | 朝向学生在真实帧上的 8 角点图（伪标签中心格） | 无标签真实样本、四旋翼机身镜像对称 | 旧：水平翻转增广只让两个视图各自去贴同一个带噪伪标签，同一帧两视图仍不一致（所以部署镜像读数还能 −0.6°）→ 直接约束同一帧两视图一致；换算自检：正确换算分歧 0.10、只翻转 0.33 |
| 3+4 | 教师分歧引导的原型再分配 | 测距学生：真实伪目标损失 × ρ_p，中间域精确标签损失 × 1/ρ_p | RGB 原型（读数头隐层聚类）、红外⇄LiDAR 分歧、中间域（仿真机身 + 真实单帧背景，精确标签） | 旧①：逐帧可靠度信号弱（与误差秩相关 0.13–0.44）、逐帧加权不稳 → 改成"同一原型里很多帧的分歧散布"，用很多帧估一个方差，稳得多；旧②：原型密度比加权贴图（11-08）持平——它按"像不像真实"加权，和误差无关 → 这次按"教师在这类外观上吵得多凶"加权，直接对应伪目标噪声；旧③：中间域换背景 / 改前景持平或变差——那是改素材 → 这次不改素材，只决定在哪类外观上多信精确标签 |

权重全部不调：合并 w=0.15（与部署同一个数）；一致度尺度 τ、原型可靠度都用数据自身稳健尺度；镜像损失权重 = 伪标签关键点损失权重 12；原型数 K=32、截断 [1/4, 4] 与 11-08 原型代码相同。
对照：原伪目标用同一流程重训一次（量重训本身的波动）；逐帧一致度加权（看原型汇总是否必要）。

## 4. 结果：朝向镜像等变一致损失 —— 成立（3/3 种子、验证与测试都变好）

单网（严格单帧 AdaBN 后，部署裁窗读数；同一评测脚本 ou_eval_w23 / tta_eval），现最终配方 PSP vs 加镜像一致损失 PSPM，种子 0–2 平均：

| 指标 | 验证 PSP → PSPM | 测试 PSP → PSPM |
|---|---|---|
| 航向均值（只读原图） | 16.68 → **15.56**（−1.12°，3/3） | 10.51 → **9.37**（−1.14°，3/3） |
| 航向中位 | 13.47 → 12.12 | 6.75 → 6.03 |
| 几何（测地）均值 | 21.42 → 20.38 | 14.76 → 13.79 |
| 航向均值 mavic2 / phantom4 | 20.43→19.01 / 12.24→11.48 | 15.76→14.20 / 8.64→7.65 |
| 航向均值（原图 + 镜像两次读数） | 16.07 → **15.37**（−0.70°） | 9.88 → **8.90**（−0.98°） |
| 倾斜中位 | 9.00 → 9.05（不变） | 7.06 → 7.17（不变） |

为什么更好（原理）：
- 镜像是精确对称：同一架飞机，图像左右翻转 ⇔ 机身按 y 轴镜像、角点按固定规则换号。真实帧没有标签，但这条关系对每一帧都严格成立 → 给真实帧提供了一个**不带伪标签噪声的监督信号**。
- 旧的水平翻转增广只是让每个视图各自去贴同一个带噪伪标签；两个视图各自的偏差（对背景、光照这类不对称线索的依赖）互不约束，所以部署时两次读数平均还能降 0.6°。
- 一致损失直接惩罚"两次读数不一致"，网络就只能依赖在镜像下行为确定的东西——机身几何本身，而不是背景里不对称的杂物。
- 证据：加了一致损失的网络**只读原图**（测试 9.37°）就已经好于旧网络**读两次再平均**（9.88°）；即一致损失带来的不只是"把测试时平均学进网络"，而是更好的真实域泛化。mavic2（仿真里没有的机型）降得最多（−1.56°）。

## 5. 结果：位置（测距学生，种子 5–7，整链朝向固定为原最终版镜像 10 成员，常数 = 无标签训练集）

| 臂 | 验证 不合并 | 测试 不合并 | 测试位置误差（中位） | 验证 部署合并 0.15 | 测试 部署合并 0.15 |
|---|---|---|---|---|---|
| 原最终版 3 种子（XFRst 5–7，旧训练） | 62.76 | 67.81 | 0.239（0.179） | 64.43 | 71.03 |
| 对照：原伪目标同流程重训 | 63.53 | 68.47 | 0.232（0.174） | 65.23 | 71.51 |
| **合并伪目标** | **64.26** | **69.87** | **0.224（0.158）** | **65.57** | **72.25** |
| 合并伪目标 + 教师分歧原型再分配 | 63.85 | 69.97 | 0.223（0.156） | 65.51 | 72.54 |
| 合并伪目标 + 逐帧一致度加权 | 64.20 | 69.84 | 0.223（0.161） | 65.64 | 72.24 |

- **合并伪目标成立**：三个带合并伪目标的臂（共 9 个网络）都比同时重训的对照高 验证 +0.3~0.7 / 测试 +1.4~1.5（学生单独）；测试平均精度 +2.6~2.8。重训本身的波动约 0.7（对照 vs 原 3 种子）。
- 原理：学生照抄老师的错；目标先由两种误差几乎不相关的教师平均，逐帧误差少约 10% → 学生学到的错少。LiDAR 教师的知识一部分进了彩色测距学生本身 → 部署时再合并的额外收益变小（+3.0 → +2.4），叠加后总提升 +0.3~0.7。
- **原型再分配：持平**（相对合并伪目标：验证 −0.41 / 测试 +0.10；部署合并后 −0.06 / +0.29）。原因（推测）：原型可靠度 ρ 在 0.4–4 之间，但真实裁窗平均 ρ≈1.35、中间域样本平均权重≈0.97——重分配幅度小；合并伪目标已经把伪目标噪声降了一截，剩下的噪声在原型间差别不大。
- **逐帧一致度加权：持平**（与合并伪目标几乎相同）。与 11-08 朝向互验筛帧、逐帧可靠度加权的结论一致：重新分配权重不如直接把目标做准。

区间（按视频段整簇 bootstrap 300 次，合并伪目标 − 同时重训对照，3 种子）：
- 学生单独：验证 +0.74 [+0.05, +1.24]，测试 **+1.40 [+0.57, +2.02]**；测试平均精度 +2.65 [+1.24, +3.67] —— 两个集合都不跨 0。
- 再加部署合并 0.15：验证 +0.34 [−0.39, +0.91]，测试 +0.73 [+0.03, +1.18]；部署合并 0.20：验证 +0.18、测试 +0.22（都跨 0）。
- 解读：合并伪目标让彩色学生自己吸收了 LiDAR 教师的一部分知识（学生单独显著变好）；部署时再合并的额外收益相应变小，叠加后的净增益小且只在测试显著。
