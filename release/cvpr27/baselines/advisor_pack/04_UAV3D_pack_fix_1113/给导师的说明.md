# 11-13 一键修复：修好失败的任务，所有训练接着跑

```bash
conda activate uav3d
bash fix_all_1113.sh
```

默认的实验包路径是 `/userhome/public/zoulk/S2MUAV3D_pack/UAV3D_baselines_pack`。路径不同的话，加在命令后面：`bash fix_all_1113.sh <实验包路径>`。

不用停任何东西。正在跑的任务不受影响，跑完后会自动接新任务。

**脚本会做这几件事：**

1. **修复 MonoCD：**
   - 原来 MonoCD 全部失败，报错是 `Pin memory thread exited unexpectedly`。
   - 改成单进程读数据，只影响读数据的速度，不影响结果。
   - 修完先跑 5 步冒烟测试，确认没问题再继续。
2. **修复焦距统一版：**
   - 原来所有 antifu 任务都失败：预测脚本不认 `outdoor_test_fu` 这类数据集名。
   - 已训好的模型（比如 GUPNet 已经训完 140 轮的那个）会保留，重跑时直接从预测开始。
   - 焦距统一的数据如果不全，会自动先生成。
3. **失败任务重新排队，调整顺序：**
   - 所有失败任务重新排队。
   - 先补主表缺的 MonoCD 室外一行，其余任务全部保留。
4. **自动开工：** 在空闲的显卡上开工。

改动前的文件都备份成了 `*.bak_1113`。

**运行完请把屏幕最后的"各任务状态"发给我们。**

如果中途出现 `!!`，脚本会停下，把整屏输出发给我们就行。

全部跑完后：

```bash
bash scripts/collect_results.sh
```

把生成的 `results_to_send_*.zip` 发回来。

## 服务器卡住、需要全部停掉时

```bash
bash restart_1113.sh
```

这一条命令会依次完成：

1. 停掉本实验包的所有任务。只停你账号下、命令行里带这个实验包路径的进程，别人的进程不受影响。
2. 清掉"进行中"标记。
3. 自动调用 `fix_all_1113.sh`，在空闲的卡上重新开工。

被停的任务会从各自最近的存档接着训，不会从头开始：

- MonoDGP / MonoDETR / MonoCoP / MonoCD：每轮存一次，最多损失一轮。
- GUPNet：每 10 轮存一次。

已完成的任务不会重跑。

先确认是否真的需要停。任务都是用 nohup 在后台跑的，xterm 崩了不会影响它们。可以先运行 `nvidia-smi` 和 `tail runs/STATUS.txt` 看看：如果卡上还在跑、STATUS 也在更新，说明任务没事，只是终端卡了，重新登录即可，不用停。
