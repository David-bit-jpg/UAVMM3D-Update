# 对比实验包：11-12 两个补丁的操作说明

您手上是 11-11 的实验包，昨天开始跑的。它有两处要更新：

| 补丁 | 文件 | 作用 |
|---|---|---|
| ① 数据更新 | `UAV3D_pack_update_1112.zip`（1.36 GB） | AntiUAV3D 换成新划分（内参经图像核实），新增可选的"焦距统一"实验 |
| ② 修复 | `UAV3D_pack_hotfix_1112c.zip`（9 KB） | 修好昨天几乎全部失败的原因：代码路径占位符没替换、MonoCD 缺两个配置文件 |

**已经训练好的模型都会保留，不用重训；被停掉的任务会从最后保存的轮次接着训。**

下面命令里的 `PACK` 是实验包的根目录（里面有 `scripts/`、`data/`、`runs/`）。

## 操作步骤（约 10 分钟）

```bash
conda activate uav3d
PACK=/userhome/public/zoulk/S2MUAV3D_pack/UAV3D_baselines_pack

# 1. 先停掉还在跑的任务（数据要换，不能边跑边换；停掉的任务之后会从断点接着训）
pkill -u $USER -f "runs/queue"        # 停掉各卡的"领任务"工人
pkill -u $USER -f "scripts/run.sh"    # 停掉正在执行的任务
pkill -u $USER -f "$PACK"             # 停掉这些任务的训练 / 预测进程
sleep 10; nvidia-smi                  # 确认您自己的进程都已退出
rm -rf $PACK/runs/queue/*.lock        # 清掉被停任务的"进行中"标记

# 2. 解压两个补丁（任意位置，比如家目录）
cd ~
unzip -o UAV3D_pack_update_1112.zip
unzip -o UAV3D_pack_hotfix_1112c.zip

# 3. 先打数据更新，再打修复（顺序不能反）
bash UAV3D_pack_update_1112/apply_update.sh $PACK
bash UAV3D_pack_hotfix_1112b/fix_1112b.sh $PACK

# 4. 重新开跑（8 张卡全用）
cd $PACK
bash scripts/run_all.sh
```

第 3 步结束时，两个脚本都应该打印"完成"。如果中途报错就停下，把屏幕输出发给我们。

## 跑起来之后

- **看进度**：`cat runs/STATUS.txt`。正常情况下会陆续出现"完成"；如果还有"失败"，把 `runs/logs/` 下对应的 `.out` 文件发给我们。
- **哪些会重跑**：
  - MAV6D 相关的任务从断点接着跑；
  - 已经训好的模型只补做预测；
  - AntiUAV3D 上的自训练和加伪标签换新数据重跑；
  - 焦距统一（D 档）是新增的。
- **结果**：跑完运行 `bash scripts/collect_results.sh`，把生成的 `results_to_send_*.zip`（几 MB）发回给我们。
- **改了什么、为什么改**：详见 `UAV3D_pack_update_1112/更新说明_1112.md`。
