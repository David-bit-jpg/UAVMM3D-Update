# 对比实验包更新说明（11-12，在 11-11 包上打补丁）

**一句话：只换了 AntiUAV3D 的数据，MAV6D 部分不变。已经跑完的 MAV6D 结果都能继续用。**

## 为什么改

AntiUAV3D 用的是变焦相机。我们逐帧比对了图像和标注内参，发现有一部分片段的内参和画面对不上，会直接破坏单目测距的训练和评测：
- 内参记录的焦距跳变了（例如 11765 → 4961 → 11765 px），画面却没有缩放；
- 画面缩放了，内参却没变。

## 改了什么

1. **数据集 v2**
   - **只留内参核实过的帧**：内参和画面对得上的片段才保留。核实方法：每个焦距切换点前后，画面缩放比例必须和焦距比例一致；同一焦距的片段内，画面变焦不超过 6%。这一步只看图像和内参，不读真值。
   - **重新划分**：仍按整条序列划分，序列互不重叠。划分时让训练集和测试集的焦距分布、距离分布尽量一致，两种机型在训练集和测试集里都有。
   - **规模**：仍是 80 m 以内；无标签训练图 3,293 帧，测试集 2,624 帧（旧版 3,361 / 2,825 帧）。
2. **PCMD 教师伪标签重做**：`pcmd_teacher_pseudo_outdoor_train.pkl` 换成我们正式版方法在 v2 上那次运行给出的伪标签，共 249 帧，格式不变。
3. **测试真值**：`data/gt/outdoor_test_meta.npz` 换成 v2 测试集的真值。仍然只给打分用，任何训练都不读。
4. **新增可选项：按焦距统一缩放**（老师的建议）。`scripts/focal_unify.py` 的做法：
   - 把每张 AntiUAV3D 图像以主点为中心缩放，使焦距统一到 960 px，即室外仿真源域在 1920 宽下的焦距；
   - 缩小后放回原尺寸的黑底画布中央，同时改写内参；
   - 只缩小、不放大，因为放大会裁掉一部分视野；
   - 3D 坐标系不变，所以预测仍用原测试真值打分。

   跑法：目标域写 `antifu`，即 `tasks.txt` 里新增的 D 档。sim 步骤不重训，直接用训好的模型预测；st / kd 步骤同 B 档，只是图像换成统一后的。分数表里单独成行，标"（焦距统一）"。

   注意：AntiUAV3D 的焦距大多在 3,700 px 以上，统一到 960 后图像缩小到约 1/4，无人机只剩约 10 px 宽。如果觉得太小，可以运行 `python scripts/focal_unify.py --f-canon 3695`，统一到测试集最常见的焦距。这样测试图基本不动，只缩小长焦训练帧。
5. **我们自己的方法 PCMD 不需要这一步**：它预测的是"换算到同一标准焦距下的距离"，第二阶段还会把裁窗缩放到固定大小，相当于已经在方法内部统一了焦距。

## 怎么打补丁（5 分钟）

```bash
# 1. 先停掉正在跑的任务（或者等它跑完）
# 2. 解压后，指向 11-11 那个包的根目录：
bash UAV3D_pack_update_1112/apply_update.sh /path/to/UAV3D_baselines_pack
# 3. 接着跑，和原来一样：
bash scripts/run_all.sh
```

`apply_update.sh` 会自动做这几件事：
- 换掉 AntiUAV3D 数据和测试真值；
- 换掉 `run.sh`、`score.py`、`tasks.txt`、`README.md`、`任务清单.md`、`build_pcmd_labels.py`，旧文件留一份 `.bak_1111`；
- 把**旧的 AntiUAV3D 结果移到 `runs/_antiuav3d_v1_old/`**（不删），并清掉这些任务的完成标记；
- 生成焦距统一版数据。

## 哪些要重跑

| 已经跑过的 | 要怎么办 | 花多久 |
|---|---|---|
| MAV6D 的一切（A 档、MAV6D 上的 st / kd） | **不用动** | 0 |
| 各源域的 sim 模型（in / out / mix） | **不重训**，只补预测一次新的 AntiUAV3D 测试集（脚本自动） | 每个几分钟 |
| AntiUAV3D 上的 st / kd（B 档） | **要重跑**：伪标签和目标域训练图都换了 | 同原来的 B 档 |
| D 档焦距统一版（新增，可选） | 新跑 | sim 几分钟，st / kd 同 B 档 |

跑完照旧运行 `bash scripts/collect_results.sh`，把结果 zip 发回即可。
