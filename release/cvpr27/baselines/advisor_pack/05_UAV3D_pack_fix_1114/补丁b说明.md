# 11-14 补丁 b：把空着的 4 张卡用起来

先确认已经运行过 `fix_1114.sh`，然后：

```bash
conda activate uav3d
bash fix_1114b.sh
```

不用停任何东西，正在跑的 4 个任务不受影响。

**为什么不把慢的任务拆到多张卡上：** 这几个检测器的官方代码不支持安全的多卡训练（多卡开关会把每张图的标签切乱），多卡还会改变批大小，结果就和其他方法不可比了。所以空卡改跑 4 个能直接进论文的任务，每个约 3–8 小时：

| 任务 | 用途 |
|---|---|
| MonoCD + 干净版伪标签（MAV6D，种子 1） | 主表"换我们伪标签"列 |
| MonoCD 无标签自训练（MAV6D，种子 1） | 主表自训练列 |
| GUPNet + 干净版伪标签，种子 1、2 | 给"伪标签换给别的检测器也有效"补误差棒 |

**运行完请把屏幕上的"各任务状态"发给我们。** 约 6–8 小时后运行 `bash scripts/collect_results.sh`，把 zip 发回来。
