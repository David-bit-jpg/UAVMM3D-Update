# 11-14 一键补丁：MAV6D 换成干净版伪标签再跑一次

```bash
conda activate uav3d
bash fix_1114.sh
```

默认的实验包路径是 `/userhome/public/zoulk/S2MUAV3D_pack/UAV3D_baselines_pack`。路径不同的话，加在命令后面：`bash fix_1114.sh <实验包路径>`。

不用停任何东西。正在跑的任务不受影响，跑完后会自动接新任务。

**为什么要补**

- 11-10 包里 MAV6D 的"PCMD 教师伪标签"（4,088 帧）来自我们开发期的流程。
- 论文正式版用的是 11-13 定下的干净流程，它导出的伪标签是 5,227 帧，本补丁带了这个文件。
- 伪标签里没有任何真实标签，格式和旧文件一样。
- AntiUAV3D 的伪标签已经是干净流程的，不用重跑。

**脚本会做这几件事：**

1. **拷入干净版伪标签**：先核对每一帧都在 MAV6D 无标签训练图里。
2. **新增步骤 `kdc`**：等于原来的 `kd`，只是伪标签换成干净版，只用于 MAV6D。
   - 结果写到新目录 `runs/<方法>_in_kdc_mav_s0/`。
   - 旧的 `kd` 结果全部保留，不会被覆盖。
3. **排进队列**：GUPNet、MonoDGP、MonoDETR、MonoCoP 各跑一次 `kdc`。
   - 排在主表还缺的任务（MonoCD 室外一行、MAV6D 的 MonoDGP / MonoCoP 自训练）之后，其余任务之前。
   - 长任务先开（MonoCoP、MonoDETR 约 51 小时，MonoDGP 约 29 小时，GUPNet 约 6 小时）。
   - 其余任务一个不少，只调整顺序。
4. **自动开工**：有空闲显卡就马上开工；没有的话，哪张卡跑完当前任务就接上 `kdc`。

改动前的文件都备份成了 `*.bak_1114`。脚本可以重复运行，已改过的地方会自动跳过。只想先看看会做什么，不改任何文件：`DRYRUN=1 bash fix_1114.sh`。

**运行完请把屏幕最后的"各任务状态"发给我们。**

如果中途出现 `!!`，脚本会停下，把整屏输出发给我们就行。

GUPNet 的 `kdc` 大约 6 小时出结果。之后随时可以：

```bash
bash scripts/collect_results.sh
```

把生成的 `results_to_send_*.zip` 发回来。分数表里新的一行显示为"+ PCMD 教师伪标签（干净版）"。

## 服务器卡住、需要全部停掉时

```bash
bash restart_1114.sh
```

这一条命令会停掉本实验包的所有任务（只停你自己账号下、命令行里带实验包路径的进程），清掉"进行中"标记，然后自动运行 `fix_1114.sh`，所有任务从各自最近的存档接着训。已完成的任务不会重跑。
