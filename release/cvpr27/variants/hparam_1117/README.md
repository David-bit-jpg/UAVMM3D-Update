# 超参数敏感性表（11-17，用户批准的补充实验）

**目的**：回答“超参数是不是在测试集上调的”。四个超参数各取默认值和两侧邻值，其余一切不变。
每个配置的测试集只用 `score_x.py` 打一次分。默认值一律就是已报告的那次运行本身，不重跑。
结果表由 `collect.sh` 自动生成到 `results.md` / `results.json`，下面的表定期从那里抄过来。

### 共同规则
- 三次运行就是已有的三次 PST 运行。MAV6D 是 `srcx/in2mav`（偏移 0，即报告的 UDS 60.81）、`review1113/sup3/run`（偏移 10）、`review1113/seeds/mav_full_s20`（偏移 20）。RealDrone3D 是 `srcx/out2antifs`、`seeds/antifs_full_s10`、`seeds/antifs_full_s20`。
- 已有结果和脚本一律不改。代码都复制到本目录下的 `lib/` 里。复制件只做以下改动，每一处都有断言：
  - 输出目录改向本目录；
  - γ 改由 `$HP_GAMMA` 指定；
  - 部署输入改由 `$HP_IN` / `$HP_STU` 指定；
  - 伪朝向文件改由 `$HP_PSEUDO` 指定；
  - λ 写死在复制件里。
- 真值只通过 `score_x.py` 读取。验证集先打分，测试集每个配置只打一次。
- 显卡走 `gproto/gpu_slot.sh`（含显存闸门和 `.prio_hold`）。我们的训练同一时刻最多 1 个：两个学生、三个检测器、两个折射器都依次训练。DataLoader 的 workers 为 0。
- 训练可续跑。遇到 OOM 时 batch 减半后续跑，记入 `logs/retry.log` 并标为“配方偏离”。
- 不停任何进程。

### 各超参数的具体协议
- **γ**（`gamma.sh`，已完成）：对每次运行重跑 `chain_x.py deploy`，ω 等其余输入都用该运行自己的。先核对 γ=0.5 的预测文件与报告的完全一致（6 次运行全部逐字节一致），所以默认格直接沿用报告分数，测试集不重打。
- **门限和 λ_mir**（`stu_arm.sh`）：沿用 `review1113/sup2`（不设门限）和 `review1113/initabl` 的协议，只重训两个朝向学生，接着做 BN 重估和带镜像视图的读数（验证、测试），然后按该运行冻结的 ω、冻结的第三段深度学生、det1 和高度读数部署。
  - 换门限时，用该运行自己的 `pseudo_tr1.npz` 按 `d_il <= T` 重算 gate 标记。伪朝向本身不变。
  - “不设门限”在 MAV6D 偏移 0 上直接沿用 `review1113/sup2/nogate`（UDS 62.07），其余运行用同一协议补跑（`gall`）。
  - `rep` 格是默认值按同协议重训一次，作为重训噪声的参照。
  - 注意：这个协议不重训第三段折射器，也不重估 ω，和已有的 sup2、initabl 一致。
- **λ**（`lam_chain.sh`）：参照 `heads/run_arm.sh` 的 FULL 模式，偏移 0。第一、二段折射器和它们在 det0 训练集上的修正与 λ 无关，所以从报告运行复制。其余全部重算。
  - 输出位置：`lam/<tgt>_L<λ×100>_s0/`；裁窗放在 `D:/S2MUAV3D/srcx_work/hp_*`；新标签后缀为 `*_hpL050s0` 等。

- `hp_lane.sh` 按顺序跑所有格子，由 `local_runner_1113.sh` 的队列行 `hparam_1117` 启动。
- 每格完成后自动运行 `collect.sh`。总日志在 `logs/hparam.log`。
- 截止保护：学生格 11-24 15:00 之后不再开跑，λ 链 11-24 08:00 之后不再开跑。
- 顺序：
  1. MAV6D 偏移 0：门限 5/20、λ_mir 6/24、λ 0.5/1.0；
  2. 重训噪声参照；
  3. MAV6D 偏移 10/20 的门限（含不设）和 λ_mir；
  4. RealDrone3D 偏移 0 的门限、λ_mir、λ。

逐次运行的 MAV6D UDS（γ = 0 / 0.5 / 1.0）：
- 偏移 0：61.06 / 60.81 / 60.31；
- 偏移 10：59.54 / 59.28 / 58.71；
- 偏移 20：62.84 / 62.70 / 62.33。

解读：
- γ 只改长宽，所以 AP、位置误差、朝向误差、检出率都不变，变的只有尺寸误差。
- **γ = 0（长宽不随深度修正）在两个数据集上的尺寸误差都比默认值小**，MAV6D 的 UDS 也高 0.21。3 次运行方向一致，默认值不是测试集上的最优。
- RealDrone3D 的尺寸误差都在 10 cm 以上，UDS 的尺寸项已经封顶为 0，所以 UDS 不动。
