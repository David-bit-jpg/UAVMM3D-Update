# Per-stratum analysis of privileged modalities (IR, LiDAR) on real test frames — 11-17

Existing test predictions only (no training, no GPU). Test labels are used only to define strata and to score.
Script: `strata.py` (this directory). Raw numbers: `results.json`.

## 1. Definitions (written BEFORE any per-stratum result was computed)

**Runs (arms).** Top-1 box per frame from each prediction pickle.
- RealDrone3D (outdoor, AntiUAV3D-fs test, 2624 frames, 2 sequences), unrestricted pipeline, seed shift 0:
  `srcx/out2antifs` = PST (IR+LiDAR teachers); `out2antifs_ir` = IR-only teachers; `out2antifs_lid` = LiDAR-only teachers;
  `out2antifs_none` = RGB-only teachers; `review1113/sensorfree/E1/antifs_s0/preds/e1_fused_test.pkl` = PST w/o sensors (E1).
- MAV6D (indoor, 4800 frames, 10 sequences): `srcx/in2mav` = PST; `in2mav_none` = RGB-only; `in2mav_ir`, `in2mav_lid` are used automatically
  when `preds/pcmd_fused_test.pkl` exists (re-run the script).

**Scorer.** `D:/UAV3D_baselines_pack/scripts/score.py`, `S.metrics` restricted to the stratum's frame indices;
`S.CFG['outdoor_test']` for RealDrone3D (relative ATE, thresholds 2.5/5/10/20 % of distance), `S.CFG['real_test']` for MAV6D (metres).
Metrics: AP, ATE, ASE, AOE, mDR, UDS. GT metas: RealDrone3D `antifs_test_meta.npz`, MAV6D `cmpeval/test_meta.npz`.

**Geometry used for strata** (GT box `gt = [t(3), l w h, euler xyz]` in camera coordinates, R = Rot.from_euler('xyz')):
- distance = ||t|| (Euclidean, both targets; note the pack's own MAV6D distance bins use z, ours use ||t||).
- 2-D box = projection of the 8 GT box corners with the ORIGINAL-resolution intrinsics `K_raw` of the cache metas (1920x1080 raw image).
- UAV up axis u = R[:,2] (the box h axis, the shortest side). View vector v = -t/||t|| (UAV -> camera).

**Strata** (cut points = terciles over ALL test frames of that target; each stratum is reported for every arm):
1. `dist`: terciles of ||t|| (near / mid / far).
2. `width`: terciles of the projected 2-D box width in raw pixels (tiny = lowest tercile / medium / large).
3. `bright`: grey value (cv2 BGR->GRAY on the raw image; MAV6D raw frames undistorted to K_raw via `sx.imread_raw`, SX_SRC=in SX_TGT=mav)
   c = mean grey inside the projected GT box (clipped to the image) minus mean grey in the surrounding ring
   (box enlarged to 2x width and 2x height about its centre, minus the box). Bins: `dark-on-bright` (c < 0) and `bright-on-dark` (c >= 0).
   Additionally `|contrast|` terciles of |c| (low / mid / high). All frames are read (no subsampling) unless stated otherwise below.
4. `elev`: angle between v and u in degrees (0 = seen from straight above, 90 = edge-on, >90 = seen from below); terciles.
   `yaw`: azimuth of v in the UAV body x-y plane, a = |atan2(v.y_body, v.x_body)| folded to [0, 90] deg by a -> min(a mod 180, 180 - a mod 180);
   frontal = a < 30 (looking along the body x / length axis), oblique = 30-60, side = a >= 60 (along the body y / width axis).
   (Under the 4-fold quadrotor symmetry used by AOE front and side are physically similar; the split follows the label axes.)
5. `type`: UAV type (MAV6D: phantom4 / mavic2 from the meta cls; RealDrone3D: M4E / M400 from the meta cls; M400 = one 48-frame sequence).

**Paired differences + bootstrap.** For each stratum: A - B for UDS, AOE, ATE (also AP, mDR, ASE in results.json), for the pairs
IR-none, LiDAR-none, PST-IR, PST-LiDAR, PST-none, PST-E1 (RealDrone3D) / those available (MAV6D).
95 % CI = 2.5/97.5 percentiles over B = 2000 resamples of the WHOLE test set (same resample for all arms = paired), then restricted to
the stratum's frames (with multiplicity):
RealDrone3D: circular blocks of L = 176 consecutive test frames (meta order), ceil(2624/176) = 15 blocks, truncated to 2624;
MAV6D: resample the 10 test sequences with replacement. Seed 0. A difference is called "clear" when the CI excludes 0.
For UDS higher is better; for AOE and ATE lower is better (a negative PST - X difference in AOE/ATE = PST better).
The bootstrap uses a vectorised re-implementation of `S.metrics`; it is checked to reproduce `S.metrics` exactly on every stratum
(point estimates in the tables come from `S.metrics` itself).

## 1b. Caveats noticed after the run (definitions above NOT changed)
- RealDrone3D `bright`: 2604/2624 frames are dark-on-bright (UAV against sky); bright-on-dark has only 20 frames on which most arms
  have no true positive, so that split carries no information there. `|contrast|` terciles are the usable brightness split for RealDrone3D.
- RealDrone3D `type`: M400 = a single 48-frame sequence. Circular 176-frame blocks either contain it or not, so its CIs are degenerate
  (bounds stuck at 0); do not read M400 CIs. M4E (2576 frames) is essentially the whole test set.
- MAV6D: only 10 test sequences; per-type strata (mavic2) depend on few sequences, CIs touching 0.00 come from resamples with no such sequence.
- MAV6D IR-only / LiDAR-only arms (in2mav_ir, in2mav_lid) were still training at 11-17 21:2x; re-run `strata.py` once their
  `preds/pcmd_fused_test.pkl` exist (image features are cached in feat_*.npz, the re-run is ~3 min).
- Fast bootstrap metric reproduced S.metrics on every stratum and arm (assert, |diff| < 1e-9).
