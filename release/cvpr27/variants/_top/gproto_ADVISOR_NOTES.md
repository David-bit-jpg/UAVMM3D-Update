## 二、按论文会话的四个问题归类

### 1. 对"教师（红外、LiDAR）及其特点"的要求
- 基本框架：多模态仿真数据训练教师，单模态（RGB）学生向教师蒸馏，学生在真实数据上变好（09-23）。
- 叙事：多教师教的是"跨域鲁棒的知识"：
  - 红外传授获取高频信息（轮廓）的能力；
  - LiDAR 传授获取几何的能力（11-02）。
- 要体现"相应模态教师知识的特点"，不能是用在任何数据上都行的通用东西（11-06）。
- 原型要来自教师学到的知识，不是原始特权数据（11-07，用户纠正）。
- 原型要建在 RGB 里：如果用红外/LiDAR 建，就不仅跨域、还跨模态（11-07）。
- 具体用法：LiDAR 抽关键点提升尺寸准确性（10-17）；可按"无人机 3D 特性、红外特质"加创新（10-09）。
- "LiDAR 管机身角度、红外管距离"这类分工只算讲故事，创新要是具体模型设计（10-28）。

### 2. "针对 UDA、不是通用方案"指什么，否定过哪些做法
- 定位：sim2real 3D UDA。切入点二选一：多教师能否缩小跨域分布差异、能否提升伪标签质量，加专门 loss（10-28）。
- 自训练阶段要用到教师的知识去提升伪标签质量（11-06）；目标是真实测试集，提升伪标签质量只是手段（11-07）。
- 导师否定或质疑过的：
  - **实例原型 / 时间一致性**（跨帧剪影尺度、中位平滑）：故事不对、跟 UDA 没关系、要求目标域是连续帧、能套在别的方法上，只算后处理技巧（11-06）。
  - **两个头按置信度做结果级后融合**：保证不降，但没有创新点（10-09）。
  - **把别人的蒸馏方法换进我们框架当主对比**：不需要，主表对手应是 3D 检测方法（10-28）。
  - **贴图做得更逼真**：如果非要贴图，为什么需要教师？直接改仿真 RGB 不是更直接（11-08）。这等于说贴图和真实感不能算"教师"的贡献。
- 用户据此补充的规矩：
  - 完全不许跨帧，训练素材也不行（11-07、11-08）；
  - 跨帧原型只算数据处理技巧（11-07）。

### 3. 原型、新 loss、红外⇄LiDAR 互校的原话
- 原型：
  - "可以考虑弱化一点点我们前期做的数据增强 调整一下，突出一下原型的效果"（11-04）；
  - "原型只是其中之一"（11-07）；
  - 原型要用 RGB（11-07）；
  - 可以打破常规，把原型用在特殊的地方（11-07）。
- 新 loss："比如加多一个loss"（10-28、10-29）。
- 互校："要用uda特别设计的红外⇄LiDAR 互验 + 专门 loss，才好说故事，因为目前只是一个蒸馏方法不是专门说的"。这句是用户的话，跟在导师那句后面（11-07T23:40）。
- 打分器：两个教师分支各加打分器，评估学生学没学到教师知识，用来筛伪标签；导师自己也提出疑问：学没学到和伪标签质量是否有关联（11-08）。
- 导师给过一份"跨模态共识原型银行"方法文档（11-03）：三者框一致才进库 + 到最近原型的 L2。已判负。

### 4. 论文怎么讲
- 主线：一种特殊的 UDA。多教师教跨域鲁棒的知识（红外 = 轮廓/高频，LiDAR = 几何），学生学到后在真实域更好（11-02）。
- 目标是提升真实测试集；手段是用教师模型提升伪标签质量（11-07）。
- 要看起来是专门为这个任务设计的，体现多模态教师特点，有创新（11-06）。
- 主对比表对手是 3D 检测方法，蒸馏文献只用来证明原创（10-28）。对比口径见 10-29 夜。
- 方法完整版不用真实标签（11-02）。

## 三、据此定下的方向和现状（截至 11-08，实验会话这边）

**距离 / 位置**
- 真实帧上"用教师修伪标签"这条路已查清走不通。
- 根因：部署时的第二段测距网络本身就是教师，伪标签里跟着外观走的错误会被学回去。
- 已判负的做法：不动点伪标签；红外/LiDAR 读数融合、牵制、互检；按两路几何分组；偏差出口；原型均值目标；原型密度加权；外观移植；部署口径标签换算；四种"跳出数值"的形式。
- 保留的有效部分：单帧背景跨域贴图 + 伪目标微调。合规版（不跨帧）5 网集成，真实测试 69.46 / 验证 60.82。

**导师的打分器**
- 关联存在：LiDAR 分支打分和伪标签段内误差相关 0.1~0.34，控制几何后仍在；红外分支无信号。
- 但筛掉 30% / 50% 伪标签，测试只变 ±0.2，不涨。

**用户 11-08 新定方向：只攻朝向**（位置不降即可）
- 现成提升（讲得通就用）：集成对齐（航向 16.5° → 12.6°）、统计量重估 / AdaBN（→ 约 9°），正在严格单帧口径下复现。
- 新发现：朝向网络把背景当视角线索。机身不动只换背景，误差 7.9° → 18.7°；同场景合成对照只 8.6°。
- 换景贴图训练朝向网络（1 种子小测，真实验证集）：
  - 整体朝向误差 27.3° → 22.8°（对比同预算纯续训）；
  - 叠加统计量重估：25.3° → 22.5°。
- 方法框架（待做）：
  - 互验：彩色成员与红外+LiDAR 成员在对称空间一致才算验证通过（离线：一致帧伪朝向 15.2°，不一致 22.1°）；
  - 原型：RGB 特征里的视角原型；
  - loss：原型条件化的统计量对齐 + 对称感知原型对比损失。
- 待办：原型损失那组的评测、3 种子确认、测试集、接上集成对齐。
